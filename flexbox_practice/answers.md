ВОПРОС 1
Какое основное свойство CSS включает Flexbox и что происходит
с дочерними элементами после его применения?

Основное свойство — display: flex; (или display: inline-flex;).
Оно применяется к родительскому контейнеру и превращает его
во flex-контейнер.

После применения:
- Все прямые дочерние элементы становятся flex-элементами
  (flex items).
- Они выстраиваются в одну линию вдоль главной оси (main axis),
  по умолчанию — в строку.
- Элементы получают возможность растягиваться, сжиматься
  и менять порядок.
- Свойства float, clear, vertical-align для детей перестают
  работать.

Пример:

  .container {
    display: flex;
  }


ВОПРОС 2
В чём разница между justify-content и align-items?
Приведите примеры использования каждого.

justify-content выравнивает элементы вдоль ГЛАВНОЙ оси
(main axis). По умолчанию главная ось — горизонтальная.

align-items выравнивает элементы вдоль ПОПЕРЕЧНОЙ оси
(cross axis). По умолчанию поперечная ось — вертикальная.

Значения justify-content: flex-start, flex-end, center,
space-between, space-around, space-evenly.

Значения align-items: stretch (по умолчанию), flex-start,
flex-end, center, baseline.

Пример justify-content:

  .header {
    display: flex;
    justify-content: center;  /* по центру по горизонтали */
  }

Пример align-items:

  .content {
    display: flex;
    align-items: center;  /* по центру по вертикали */
  }


ВОПРОС 3
Что делает свойство flex-direction и какие значения может
принимать? Как оно влияет на основную ось?

flex-direction задаёт направление ГЛАВНОЙ оси, вдоль которой
располагаются flex-элементы.

Значения:
- row (по умолчанию) — слева направо, главная ось горизонтальна.
- row-reverse — справа налево.
- column — сверху вниз, главная ось вертикальна.
- column-reverse — снизу вверх.

Влияние: при изменении flex-direction меняется направление
главной оси. Это значит, что justify-content начинает работать
по вертикали (если column), а align-items — по горизонтали.

Пример:

  .main {
    display: flex;
    flex-direction: column;   /* главная ось — вертикальная */
    justify-content: center;  /* теперь центрирует по вертикали */
  }


ВОПРОС 4
Объясните значение трёх свойств в сокращённой записи flex: 1.
Что означают flex-grow, flex-shrink и flex-basis?

Запись flex: 1 — это сокращение для:

  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 0%;

flex-grow — во сколько раз элемент может РАСТИ относительно
других. 1 — растёт, 0 — не растёт.

flex-shrink — может ли элемент СЖИМАТЬСЯ при нехватке места.
1 — сжимается, 0 — нет.

flex-basis — БАЗОВЫЙ размер элемента до применения grow/shrink.
Может быть auto, 0, 200px, 30% и т.д.

Пример: flex: 1 означает «займи всё доступное пространство
поровну с другими flex: 1».

flex: 0 0 200px — фиксированная ширина 200px, не растёт
и не сжимается.

ВОПРОС 5
Как работает свойство flex-wrap и в каких случаях его
следует использовать?

flex-wrap определяет, ПЕРЕНОСЯТСЯ ли flex-элементы на новую
строку, если не помещаются в контейнер.

Значения:
- nowrap (по умолчанию) — все элементы в одну линию,
  могут сжиматься.
- wrap — элементы переносятся на новую строку.
- wrap-reverse — переносятся, но в обратном порядке.

Когда использовать: когда элементов много и они должны
переноситься (например, карточки товаров, галерея).
Без wrap они сожмутся до нечитаемого состояния.

Пример:

  .content {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
  }


ВОПРОС 6
Чем отличается align-content от align-items и когда
применяется каждое из этих свойств?

align-items выравнивает ЭЛЕМЕНТЫ внутри одной линии
по поперечной оси. Работает всегда.

align-content выравнивает ЛИНИИ (ряды) внутри контейнера
по поперечной оси. Работает только если flex-wrap: wrap
и есть НЕСКОЛЬКО линий.

align-items — выравнивает элементы в каждой строке
(например, по центру по вертикали).

align-content — выравнивает сами строки относительно
друг друга (например, space-between распределяет строки
по высоте контейнера).

Если линия одна — align-content не действует.

ВОПРОС 7
Как свойство order влияет на отображение элементов
и в каких практических ситуациях оно может быть полезно?

order меняет ПОРЯДОК отображения flex-элементов,
не изменяя HTML-структуру. По умолчанию order: 0.
Элементы с меньшим order показываются раньше.

Полезно:
- Адаптивность: на мобильных вывести важный блок вверх.
- Изменение порядка карточек/секций без правки HTML.
- Доступность: логичный порядок в HTML, визуально другой.

Пример:

  .card:nth-child(1) { order: 2; }
  .card:nth-child(2) { order: 1; }
  .card:nth-child(3) { order: 3; }


ВОПРОС 8
Что такое «осевая линия» (main axis) и поперечная ось
(cross axis) в Flexbox и как они связаны с flex-direction?

Главная ось (main axis) — направление, вдоль которого
располагаются flex-элементы. Задаётся flex-direction.

Поперечная ось (cross axis) — перпендикулярна главной.

Связь с flex-direction:

  flex-direction: row
    Главная ось — горизонтально (слева направо)
    Поперечная ось — вертикально (сверху вниз)

  flex-direction: column
    Главная ось — вертикально (сверху вниз)
    Поперечная ось — горизонтально (слева направо)

  flex-direction: row-reverse
    Главная ось — горизонтально (справа налево)

  flex-direction: column-reverse
    Главная ось — вертикально (снизу вверх)

justify-content работает по главной оси, align-items —
по поперечной. Поэтому при смене flex-direction
их действие «переворачивается».


ВОПРОС 9
Как создать адаптивный макет с помощью Flexbox без
использования медиа-запросов? Приведите пример.

Используя flex-wrap: wrap + flex-basis + min-width
(или flex: 1 1 200px). Элементы сами переносятся,
когда не помещаются.

Пример:

  .content {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
  }

  .card {
    flex: 1 1 200px;   /* минимум ~200px, растёт при возможности */
    min-width: 200px;
  }

Когда ширина контейнера уменьшается, карточки переносятся
на новую строку автоматически — без @media. Это называется
«intrinsic responsiveness» (внутренняя адаптивность).


ВОПРОС 10
Какие преимущества даёт использование gap вместо margins
для создания промежутков между flex-элементами?

Преимущества gap:

1. Не нужно ставить margin каждому элементу — только контейнеру.
2. Нет «крайних» отступов — gap не добавляет отступ по краям
   контейнера (в отличие от margin).
3. Не схлопывается (в отличие от margin collapse).
4. Работает и по строкам, и по колонкам одновременно
   (row-gap и column-gap).
5. Проще адаптивность — при переносе элементы сохраняют
   одинаковые отступы.
6. Не влияет на ширину — не нужно вычитать margin
   из flex-basis.

Пример:

  /* Было с margin: */
  .card { margin: 0 0.5rem; }   /* лишние отступы по краям */

  /* Стало с gap: */
  .content { display: flex; gap: 1rem; }   /* чисто и удобно */
