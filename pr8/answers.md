Инструменты Figma: панель Properties (размеры, отступы), Dev Mode (CSS), Color Picker, Style/Text Styles, Inspect.

CSS-переменные: группировать по смыслу (цвета, типографика, тени, отступы), называть семантически (--primary, а не --blue), хранить в :root.

Критичные метрики: ширина контейнера, отступы между секциями, размеры шрифтов и line-height, цвета.

Сетка: посчитать колонки в макете (обычно 12), замерить gutter, перенести в grid-template-columns: repeat(12, 1fr) или repeat(3, 1fr).

Сложности типографики: разные единицы (px/pt), сглаживание шрифтов, fallback-шрифты, разная высота строк.

Адаптивность без мобильного макета: mobile-first, breakpoints 768/1024, логика «схлопывания» сеток, стандартные паттерны.

Инструменты браузера: DevTools (Inspect, Computed, Rulers), PixelPerfect-расширения, наложение скриншотов.

Экспорт изображений: SVG для иконок/логотипов, WebP/PNG для фото, 1x/2x для retina, оптимизация через TinyPNG/Squoosh.

Отсутствующие шрифты: Google Fonts, аналоги (Roboto → Inter), @font-face с локальным файлом, fallback-стек.

Методологии: БЭМ, CSS-переменные, дизайн-токены, Storybook, регулярное сравнение через CI-скриншоты.
