# Ответы на вопросы для самоконтроля

## 1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?

Основное свойство — display: grid. 

Отличия от Flexbox:
CSS Grid — двумерная система (работает одновременно по строкам и столбцам). Позволяет размещать элементы в произвольных ячейках, накладывать их друг на друга, задавать именованные области.
Flexbox — одномерная система (работает либо по строке, либо по столбцу). Хорош для выравнивания и распределения элементов вдоль одной оси.
Grid лучше подходит для создания целых макетов страниц, Flexbox — для компонентов (меню, карточки, кнопки).

## 2. В чем разница между grid-template-columns и grid-auto-columns?

grid-template-columns — задаёт явные (заранее определённые) столбцы сетки. Элементы, помещённые в эти столбцы, следуют заданной структуре.
grid-auto-columns — задаёт размер неявных столбцов, которые создаются автоматически, когда элемент выходит за пределы явной сетки (например, при grid-column: 5, если явных столбцов только 3).

`grid-template-columns` используется, когда структура известна заранее; grid-auto-columns — когда количество элементов динамическое.

## 3. Что делают функции repeat(), minmax() и auto-fit?

repeat(n, size) — повторяет определение столбцов/строк n раз. Например: repeat(4, 1fr) = 4 колонки по 1fr.
minmax(min, max) — задаёт диапазон размера: не меньше min, не больше max. Пример: minmax(200px, 1fr).
auto-fit — автоматически подбирает количество колонок, растягивая их на всю доступную ширину контейнера. Пустые колонки схлопываются.

Пример:
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

Создаёт столько колонок по 250px минимум, сколько поместится, и растягивает их на всю ширину.
## 4. Как работают именованные grid-области и какие преимущества они дают?

Именованные области задаются через grid-template-areas:
css

grid-template-areas:
    "header header"
    "nav    main"
    "sidebar footer";

Каждое имя — это ячейка. Одинаковые имена объединяются в одну область. Элементы привязываются через grid-area: header;.

Преимущества:

    Наглядность: макет виден прямо в CSS.

    Легко переставлять блоки (например, для адаптивности — просто переписать шаблон в медиа-запросе).

    Упрощает создание сложных двумерных макетов.

## 5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.

Линии сетки нумеруются с 1. Например, при 3 колонках есть 4 вертикальные линии (1, 2, 3, 4).

    grid-column: 1 / 3 — элемент занимает от 1-й до 3-й линии (2 колонки).

    grid-row: 2 / 4 — элемент занимает со 2-й по 4-ю линию (2 строки).

    Можно использовать span: grid-column: span 2 — растянуть на 2 колонки.

Пример:

.gallery-item:nth-child(3) {
    grid-column: span 2;
}

## 6. Что такое grid-gap (или gap) и чем он лучше margins?

gap (ранее grid-gap) — задаёт расстояние между строками и столбцами сетки:
css

gap: 1.5rem;

Преимущества перед margin:

    Не нужно думать о «крайних» элементах — gap не добавляет отступы по краям контейнера.

    Не схлопывается (в отличие от margin).

    Работает симметрично и предсказуемо.

    Не влияет на размеры элементов, а только на промежутки.

## 7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?

    justify-items — выравнивает содержимое ячеек по горизонтали (start, center, end, stretch).

    align-items — выравнивает содержимое ячеек по вертикали (start, center, end, stretch).

Применяются ко всем дочерним элементам контейнера. Значение по умолчанию — stretch.

Пример:

.gallery {
    align-items: start;
    justify-items: center;
}

## 8. В чем разница между auto-fill и auto-fit?

    auto-fill — создаёт максимально возможное количество колонок, даже если они пустые. Пустые колонки сохраняют место.

    auto-fit — создаёт столько колонок, сколько поместится, но пустые колонки схлопываются, а существующие растягиваются на всю ширину.

Пример:
css

/* auto-fill: 3 элемента, 5 колонок — 2 пустые */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

/* auto-fit: 3 элемента растянутся на всю ширину */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

## 9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?
css

.grid-container {
    display: grid;
    grid-template-areas:
        "header header header"
        "nav    main   aside"
        "footer footer footer";
}

.header  { grid-area: header; }
.nav     { grid-area: nav; }
.main    { grid-area: main; }
.aside   { grid-area: aside; }
.footer  { grid-area: footer; }

Правила именования:

    Имя области — любое слово без пробелов (можно использовать дефисы и подчёркивания).

    Область должна быть прямоугольной (нельзя «Г»-образную форму).

    Точка . обозначает пустую ячейку.

    Количество значений в строке = количеству колонок.

## 10. Какие преимущества дает CSS Grid перед другими методами верстки?

    Двумерность — одновременное управление строками и столбцами.

    Наглядность — grid-template-areas позволяет «рисовать» макет прямо в CSS.

    Гибкость — легко менять порядок, размеры и расположение элементов.

    Адаптивность — auto-fit, minmax, медиа-запросы позволяют создавать отзывчивые макеты без лишних хаков.

    Управление промежутками — gap вместо margin.

    Наложение элементов — можно размещать несколько элементов в одной ячейке.

    Совместимость с Flexbox — Grid и Flexbox дополняют друг друга: Grid для макета, Flexbox для компонентов.
