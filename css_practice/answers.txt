ОТВЕТЫ НА ВОПРОСЫ ДЛЯ САМОКОНТРОЛЯ (ПР №3)

1. В чем разница между селектором по классу и по ID с точки зрения
специфичности и возможности повторного использования?
Класс (.) имеет специфичность 0,1,0 и может использоваться многократно на
странице. ID (#) имеет специфичность 1,0,0 и должен быть уникальным на
странице — только один элемент с таким id. ID сложнее переопределить,
поэтому для стилей лучше использовать классы.

2. Как работает каскад в CSS и в каком порядке применяются стили при
конфликте правил?
Каскад — это механизм разрешения конфликтов. Порядок приоритета:
1) !important, 2) специфичность селектора, 3) порядок объявления в коде
(позже — приоритетнее). Если специфичность одинакова — побеждает то
правило, которое объявлено ниже.

3. Рассчитайте специфичность для селекторов:
- ul li.important → 0,1,2 (один класс + два тега)
- #site-title → 1,0,0 (один ID)
- .content > .featured-post → 0,2,0 (два класса)

4. Какие свойства в CSS наследуются по умолчанию, а какие нет?
Наследуются: font-family, font-size, color, line-height, text-align.
Не наследуются: margin, padding, border, background, width, height.
Для наследования ненаследуемых свойств используют значение inherit.

5. Как работает селектор > (дочерний селектор) и чем он отличается от
селектора потомков (через пробел)?
.content > article — выбирает только прямых детей article внутри .content.
.content article — выбирает всех потомков article на любой глубине.
Дочерний селектор строже, потомков — шире.

6. Для чего используются псевдоклассы :hover и :nth-child()? В каких
практических задачах они могут пригодиться?
:hover — при наведении курсора (кнопки, ссылки, меню).
:nth-child() — выбор элементов по позиции (чётные/нечётные строки таблицы,
каждый третий элемент и т.д.). Часто применяются для интерактивности и
чередования фона.

7. Что делает правило !important и почему его следует использовать с
осторожностью?
!important переопределяет любые другие правила, включая более специфичные.
Использовать осторожно, потому что он ломает естественный каскад, усложняет
отладку и поддержку кода. Применять только в крайних случаях.

8. Как псевдоэлементы ::before и ::after расширяют возможности CSS и какой
контент они могут содержать?
Они добавляют контент до или после элемента без изменения HTML. Могут
содержать текст, символы (стрелки, звёздочки), иконки, изображения.
Часто используются для декоративных элементов, иконок, кавычек.

9. В каком порядке браузер применяет CSS-правила при одинаковой
специфичности селекторов?
При одинаковой специфичности побеждает правило, объявленное позже в коде
(или в подключённом позже файле). Если один и тот же файл — то ниже
расположенное правило.

10. Как инструменты разработчика в браузере помогают анализировать и
отлаживать CSS-код?
DevTools показывают применённые стили, перечёркивают переопределённые,
показывают специфичность, позволяют менять значения в реальном времени,
включать/отключать правила, смотреть box-модель, наследование и
анимации. Это ускоряет отладку и эксперименты.
