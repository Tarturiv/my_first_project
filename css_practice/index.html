Основы CSS

CSS — это язык стилей для веб-страниц. Он позволяет управлять внешним видом элементов.

С помощью CSS можно настраивать цвета, шрифты, отступы, размеры, анимации и многое другое.

История Титаника

«Титаник» — британский трансатлантический пассажирский лайнер, второй из трёх судов класса «Олимпик».

Он затонул в ночь с 14 на 15 апреля 1912 года после столкновения с айсбергом.
