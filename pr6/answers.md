# Ответы на вопросы для самоконтроля

## 1. Что такое Viewport meta tag и почему он важен для адаптивного дизайна?

Viewport meta tag — это мета-тег в HTML, который сообщает браузеру, как масштабировать страницу на мобильных устройствах.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

    width=device-width — ширина страницы равна ширине экрана устройства.

    initial-scale=1.0 — начальный масштаб равен 1.

Важность: без него мобильные браузеры отображают страницу в «виртуальном» окне шириной ~980px, а затем сжимают её, что делает текст нечитаемым. Тег viewport позволяет странице корректно подстраиваться под физическую ширину экрана.


## 2. Какие основные подходы к созданию адаптивных макетов вы использовали?

В работе использовались:

    Fluid (резиновый) — контейнеры с max-width и %, гибкие сетки (grid, flex).

    Adaptive (адаптивный) — медиа-запросы под конкретные диапазоны (@media (max-width: 1024px), 768px, 480px).

    Responsive (отзывчивый) — комбинация fluid + adaptive + адаптивные изображения и типографика (clamp(), max-width: 100%).


## 3. Как работает Mobile First подход и в чём его преимущества?

Mobile First — подход, при котором базовые стили пишутся для мобильных устройств, а затем через @media (min-width: ...) добавляются стили для более широких экранов.

Преимущества:

    Простота: сначала делается главное — контент и базовая навигация.

    Производительность: мобильные устройства не загружают лишние стили.

    Прогрессивное улучшение: от простого к сложному.

    Лучший UX на мобильных, где сейчас большинство пользователей.

Отличие от Desktop First: в Desktop First базовые стили — для десктопа, а @media (max-width: ...) «понижают» их для мобильных.


## 4. Какие единицы измерения наиболее предпочтительны для адаптивной верстки?

    rem — относительно font-size корневого элемента (html). Удобно для типографики и отступов, легко масштабировать.

    % — для ширины контейнеров и гибких элементов.

    vw / vh — для элементов, зависящих от размера окна (hero-секции, крупные заголовки).

    em — относительно родителя, удобно для компонентов.

    px — только для фиксированных мелочей (бордеры, тени).

Почему: относительные единицы автоматически подстраиваются под размер экрана и настройки пользователя.


## 5. Как функция clamp() помогает создавать адаптивную типографику?

clamp(min, preferred, max) задаёт значение, которое плавно меняется в заданных пределах.

Пример:

.hero h2 {
    font-size: clamp(1.5rem, 5vw, 2.5rem);
}

    Минимум — 1.5rem (на маленьких экранах).

    Предпочтительно — 5vw (пропорционально ширине окна).

    Максимум — 2.5rem (на больших экранах).

Преимущество: не нужны отдельные медиа-запросы для каждого размера — шрифт плавно масштабируется.


## 6. Какие основные брейкпоинты вы использовали и как определили эти значения?

    1200px+ — десктоп (базовые стили).

    1024px — планшет (горизонтальный).

    768px — планшет/мобильный переход.

    480px — маленькие мобильные.

Значения выбраны по типовым размерам популярных устройств (iPad, iPhone, Android) и по точкам, где ломается сетка (3 колонки → 2 → 1).


## 7. Как медиа-запросы @media помогают создавать адаптивные стили?

Медиа-запросы применяют CSS-правила только при выполнении условия (ширина, высота, ориентация, плотность пикселей).

Синтаксис:

@media (max-width: 768px) {
    .nav-menu {
        display: none;
    }
}

Также можно комбинировать:
css

@media (max-width: 768px) and (orientation: landscape) { ... }


## 8. В чём разница между max-width и min-width в медиа-запросах?

    max-width: 768px — стили применяются, если ширина меньше или равна 768px. Используется в Desktop First.

    min-width: 768px — стили применяются, если ширина больше или равна 768px. Используется в Mobile First.

Когда использовать: min-width — современный стандарт (Mobile First), max-width — если проект уже написан под десктоп.


# 9. Как сделать изображения адаптивными и какие CSS-свойства используются?
css

img {
    max-width: 100%;
    height: auto;
}

    max-width: 100% — изображение не выходит за пределы контейнера.

    height: auto — сохраняет пропорции.

Дополнительно:

    srcset и sizes в HTML — для загрузки разных версий изображения.

    <picture> — для art direction.

    object-fit: cover — для корректной обрезки.


## 10. Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?

    DevTools (F12) — вкладка Elements для CSS.

    Режим адаптивного дизайна (Ctrl+Shift+M в Chrome/Firefox) — эмуляция устройств.

    Device Toolbar — выбор预设 устройств (iPhone, iPad, Galaxy).

    Ruler / измерение — проверка размеров.

    Network throttling — эмуляция медленного соединения.

    Lighthouse — аудит производительности и адаптивности.

    Responsively App — просмотр сразу на нескольких экранах.
