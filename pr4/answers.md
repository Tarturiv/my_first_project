# Ответы на контрольные вопросы

## 1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?

Основное свойство — display: flex (или display: inline-flex`). После его применения элемент становится **flex-контейнером**, а все его прямые дочерние элементы становятся flex-элементами. Они выстраиваются в одном направлении (по умолчанию — в ряд) и начинают подчиняться правилам flex-раскладки: могут растягиваться, сжиматься, менять порядок и выравниваться.


## 2. В чем разница между justify-content и align-items? Приведите примеры использования каждого.

justify-content — выравнивает flex-элементы вдоль главной оси (main axis). Пример: justify-content: space-between — элементы распределяются по всей ширине контейнера с равными промежутками между ними.
align-items — выравнивает flex-элементы вдоль поперечной оси (cross axis). Пример: align-items: cente` — элементы центрируются по вертикали (если главная ось горизонтальна).

Пример:
.container {
    display: flex;
    justify-content: center; /* по горизонтали */
    align-items: center;     /* по вертикали */
}


## 3. Что делает свойство flex-direction и какие значения может принимать? Как оно влияет на основную ось?

flex-direction задаёт направление главной оси, вдоль которой располагаются flex-элементы. Значения:

    row (по умолчанию) — слева направо;

    row-reverse — справа налево;

    column — сверху вниз;

    column-reverse — снизу вверх.

Оно определяет, какая ось будет главной, а какая — поперечной. Например, при column главная ось — вертикальная, а поперечная — горизонтальная.


## 4. Объясните значение трех свойств в сокращенной записи flex: 1. Что означают flex-grow, flex-shrink и flex-basis?

Запись flex: 1 эквивалентна flex: 1 1 0%:

    flex-grow: 1 — элемент может растягиваться, занимая свободное пространство;

    flex-shrink: 1 — элемент может сжиматься при недостатке места;

    flex-basis: 0% — базовый размер элемента равен 0, поэтому итоговый размер определяется только коэффициентом растяжения.


## 5. Как работает свойство flex-wrap и в каких случаях его следует использовать?

flex-wrap определяет, переносятся ли flex-элементы на новую строку, если не помещаются в контейнере. Значения:

    nowrap (по умолчанию) — все элементы в одну линию;

    wrap — перенос на новую строку;

    wrap-reverse — перенос в обратном порядке.

Используется, когда нужно создать адаптивную сетку карточек, которые должны переноситься при уменьшении ширины экрана.


## 6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?

    align-items — выравнивает элементы внутри одной линии (строки/столбца) по поперечной оси.

    align-content — выравнивает сами линии (ряды) относительно контейнера по поперечной оси. Работает только при flex-wrap: wrap или wrap-reverse и когда элементов больше одной строки.

align-items применяется всегда, а align-content — только в многострочных flex-контейнерах.


## 7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?

order задаёт порядок отображения flex-элементов. По умолчанию все элементы имеют order: 0. Элементы с меньшим значением отображаются раньше. Полезно, когда нужно изменить визуальный порядок без изменения HTML-структуры — например, вывести важный блок первым на мобильных устройствах.


## 8. Что такое «осевая линия» (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?

    Main axis (главная ось) — направление, вдоль которого располагаются flex-элементы. Задаётся flex-direction.

    Cross axis (поперечная ось) — перпендикулярна главной оси.

Если flex-direction: row, главная ось — горизонтальная, поперечная — вертикальная. Если flex-direction: column, главная ось — вертикальная, поперечная — горизонтальная.


## 9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.
Используя flex-wrap: wrap и flex-basis с относительными единицами. 
Пример:
.container {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}

.item {
    flex: 1 1 250px; /* растёт, сжимается, базовая ширина 250px */
}

При уменьшении ширины экрана элементы будут переноситься на новую строку автоматически, без медиа-запросов.


## 10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?

    Не нужно добавлять отступы каждому элементу и компенсировать их у контейнера.

    Промежутки не появляются по краям контейнера.

    Код становится чище и понятнее.

    gap работает равномерно между всеми элементами, включая перенос строк.

    Не влияет на размеры элементов и не требует box-sizing хаков.
